Guia do Gerador de Mapas & Dashboards

Esta página explica como configurar e executar o seu gerador para criar mapas e dashboards para Bovinos, Caprinos e Ovinos usando o painel de configurações.

Visão geral

O gerador cria mapas temáticos e dashboards a partir de arquivos CSV já estruturados. Você escolhe os anos, configura os bins (classes), define um colormap global e clica em Gerar mapas.

Dica: os shapes (geometria) utilizam o ano de shapes selecionado, enquanto os dados podem conter vários anos marcados nas caixas à direita.
Abrir painel de configurações

Pré-requisitos

  • 1) Estrutura de diretórios
    Os dados ficam em dataframes/{categoria}/{tipo}/{nível}/*.csv.
    dataframes/
  vacas/
    ordenha/
      country/*.csv
      region/*.csv
      state/*.csv
    producao/
      ...
  cabras/
    producao/
      municipality/*.csv
  ovelhas/
    produtividade/
      municipality/*.csv
  • 2) Colunas esperadas
    Cada CSV deve conter as colunas abaixo:
    ColunaDescrição
    territoryNome do país/região/estado/município (usado nos rótulos).
    abbrev_stateUF (opcional; se presente em state, rótulo vira “UF – Nome”).
    territory_codeCódigo (opcional, para referência).
    valueValor numérico usado nos mapas/gráficos.
    title, unitMetadados (opcional).
    O ano é extraído do nome do arquivo (ex.: .../state/2022_estado.csv).

Passo a passo

  1. Escolha a cultura e o tipo
    No topo do painel, selecione Bovinos, Caprinos ou Ovinos e o tipo (Ordenha, Produção, etc.).
  2. Selecione os anos
    Escolha o ano dos shapes (para as geometrias) e marque os anos de dados que deseja incluir. Use “Selecionar todos” / “Remover seleção” para agilizar.
  3. Defina os bins
    Automático (quantis), Classes Iguais (defina k) ou Manual (informe quebras ordenadas).
  4. Escolha o colormap
    O colormap global será aplicado a todos os mapas gerados.
  5. Gerar
    Clique em Gerar mapas. A barra de progresso mostra o andamento total e por grupos.
Se não houver dados para os filtros selecionados, o sistema exibirá “Não há dados para gerar os dashboards...”.

Como ler os dashboards

  • Bovinos (cow)
    Exibimos séries temporais para country, region e state, uma linha por entidade (sem somas). A legenda de region/state aparece à direita. Os nomes vêm de territory (ou UF – Nome em estados).
  • Caprinos/Ovinos
    Mostramos um Top N por ano (barras horizontais) em municipality, com um seletor para escolher a quantidade a exibir. A altura do gráfico se adapta ao número de barras.

Estrutura dos dados

Exemplo de linha em um CSV:

abbrev_state,territory_code,territory,value,title,unit
SP,35,São Paulo,12345.67,Produção de leite,"litros"

Os arquivos podem estar repetidos por entidade/ano; o backend agrega por (year, entity) quando necessário.

Erros comuns & soluções

  • “Unexpected token NaN…” no front
    Convertemos NaN/NaT para null antes do jsonify. Se aparecer, verifique se a rota está usando df.replace({np.nan: None}).
  • Sem rótulos corretos (Série 1, Série 2…)
    Garanta a coluna territory em todos os níveis. Em state, se houver abbrev_state, o rótulo vira UF – Nome.
  • Nenhum gráfico exibido
    Verifique se existe pelo menos um valor numérico em value para os anos/níveis selecionados e se o ano está presente no nome do arquivo CSV.

FAQ

Posso usar colormaps diferentes por mapa?

No painel atual, o colormap é global. É possível estender o modal para selecionar variações por nível.

Como ordenar os municípios no Top N?

Os valores são ordenados do maior para o menor automaticamente antes de aplicar o corte Top N.

Os dados aceitam separador decimal com vírgula?

Padronize os CSVs com ponto decimal (.) ou normalize antes de carregar.
